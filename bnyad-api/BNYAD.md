# BNYAD Laravel API

Full Laravel 12 backend for BNYAD / Nutrify (alternative to the Vercel API).

**Status:** In sync with [nutrify](https://github.com/ahmadosmanr3-hue/nutrify) `bnyad-api/` — June 2026.

## Deploy

See **[RAILWAY.md](./RAILWAY.md)** for Railway setup (root directory must be `bnyad-api`).

## Production API

The live app currently uses **Vercel** (`vercel-api/`), not this Laravel deploy.  
Use this folder if you want a self-hosted Laravel API instead.
